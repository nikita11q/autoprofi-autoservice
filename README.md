# АвтоПрофи — информационная система автосервиса

Учебный проект для ПМ.05 «Проектирование и разработка информационных систем».

## Функциональный модуль
Модуль оформления заявок на обслуживание автомобиля:
- ввод данных клиента и автомобиля;
- выбор услуги, даты и времени;
- проверка обязательных полей и прошедшей даты;
- сохранение заявок в `localStorage` браузера;
- отображение списка заявок;
- очистка списка с подтверждением.

## Состав проекта
- `index.html` — структура страницы и форма заявки;
- `style.css` — оформление и адаптация под мобильный экран;
- `script.js` — обработка формы, проверка и сохранение заявок;
- `.gitignore` — исключения для Git.

## Запуск
1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.
3. Заполните форму и нажмите «Отправить заявку».

Данные демонстрационной версии хранятся локально в браузере. Это не серверная база данных и не предназначено для реальных персональных данных.

## Планируемое развитие
- подключение серверной части и MySQL;
- авторизация сотрудников и разграничение ролей;
- серверная валидация и безопасное хранение паролей;
- защита от SQL-инъекций и XSS;
- журналирование действий и резервное копирование;
- улучшение адаптивности и доступности интерфейса.
