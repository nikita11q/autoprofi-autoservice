# Инструкция: загрузка проекта на GitHub

## 1. Создание репозитория
1. Войдите в свой аккаунт на https://github.com/.
2. Нажмите **New repository**.
3. Название: `autoprofi-autoservice`.
4. Выберите **Public** (если преподаватель должен видеть проект) или **Private**.
5. Не ставьте галочки добавления README, `.gitignore` и лицензии — они уже подготовлены в проекте.
6. Нажмите **Create repository**.

## 2. Загрузка проекта через GitHub Desktop (самый простой способ)
1. Установите GitHub Desktop: https://desktop.github.com/.
2. Распакуйте архив проекта в отдельную папку.
3. В GitHub Desktop выберите **File → Add local repository**. Если программа сообщит, что папка не является Git-репозиторием, выберите **Create a repository** и укажите эту папку.
4. В поле Summary напишите `Первоначальная версия проекта АвтоПрофи`.
5. Нажмите **Commit to main**.
6. Нажмите **Publish repository**, выберите созданный репозиторий `autoprofi-autoservice` и подтвердите публикацию.

## 3. Если используете терминал
Откройте терминал в папке проекта и выполните команды (вместо USER укажите свой логин GitHub):

```bash
git init
git add .
git commit -m "Создана начальная структура проекта АвтоПрофи"
git branch -M main
git remote add origin https://github.com/USER/autoprofi-autoservice.git
git push -u origin main
```

## 4. Осмысленные коммиты по этапам
Если файлы уже были загружены одним коммитом, дальнейшие изменения фиксируйте отдельно:
```bash
git add index.html
git commit -m "Добавлена форма оформления заявки"

git add style.css
git commit -m "Оформлен адаптивный интерфейс формы"

git add script.js
git commit -m "Реализованы проверка и сохранение заявок"

git add README.md GITHUB_ИНСТРУКЦИЯ.md
git commit -m "Добавлена документация проекта"
git push
```
Не создавайте фиктивные коммиты задним числом: коммитьте реальные изменения по мере работы.

## 5. Что показать преподавателю
- страницу репозитория с названием проекта;
- список файлов `index.html`, `style.css`, `script.js`;
- вкладку **Commits** с историей изменений;
- работающий модуль в браузере.

**Важно:** репозиторий создаётся в вашем аккаунте. Этот архив подготовлен к загрузке, но сам репозиторий не создан и не опубликован автоматически.
